# 8차시 기록 — 표준화와 로지스틱 회귀

## 10101 홍길동
- 오늘 결정한 것: 먼저 로지스틱 회귀로 시작하기로 했다. 수업에서 배운 분류 방법이고, 결과를 설명하기 쉽다. 다른 모델과의 비교는 첫 결과를 기준선과 비교한 뒤에 하기로 했다.
- AI에게 보낸 프롬프트(원문): 학습 데이터로 양품과 불량을 분류하는 로지스틱 회귀 모델을 만들고, 시험 데이터의 정확도를 보여 줘. 빈칸은 학습 데이터의 중앙값으로 채우는 방식을 그대로 사용해 줘.
- AI가 준 것 중 고치거나 버린 것과 그 이유: AI가 "정확도 87%면 꽤 괜찮은 모델"이라고 설명을 붙였는데 받아들이지 않았다. 정확도 0.873은 기준선 0.933보다 낮다. 화면에 모델 정확도를 보여 줄 때 기준선을 항상 옆에 같이 보여 주게 했다.
- 느낀 점: 기준선을 먼저 만들어 두지 않았으면 87%를 보고 좋아했을 것 같다.

## 10102 김영희
- 오늘 결정한 것: 센서 값을 표준화한 뒤 학습하기로 했다. 센서마다 값의 크기가 달라서다.
- AI에게 보낸 프롬프트(원문): 센서마다 값의 크기가 많이 달라. 어떤 센서는 0 근처이고 어떤 센서는 수천이야. 모델에 넣기 전에 센서 값을 표준화해 주고, 표준화 기준도 학습 데이터에서만 계산해 줘.
- AI가 준 것 중 고치거나 버린 것과 그 이유: AI의 첫 코드는 표준화 없이 학습해서 학습이 끝까지 되지 않았다는 경고가 나왔다. 표준화를 넣자 경고가 사라졌다. AI가 표준화를 전체 데이터에서 하려고 해서 학습 데이터 기준으로 고쳤다.
- 느낀 점: 6차시에 중앙값을 학습 데이터에서만 계산한 것과 같은 이유라서 이번에는 바로 알아챘다.

## 10103 이철수
- 오늘 결정한 것: 혼동행렬을 처음 확인했다. 가중치를 끈 모델은 불량 21장 중 3장을 잡고, 양품 22장을 불량으로 잘못 판정했다.
- AI에게 보낸 프롬프트(원문): 로지스틱 회귀 결과로 혼동행렬을 히트맵으로 그려 줘. 세로는 실제, 가로는 예측이고, 칸마다 웨이퍼 수를 적어 줘. 이름은 0과 1 대신 양품과 불량으로 해 줘.
- AI가 준 것 중 고치거나 버린 것과 그 이유: AI가 히트맵의 칸에 비율(%)만 적어서 장 수로 바꿔 달라고 했다. 불량이 21장뿐이라 비율보다 "21장 중 3장"이 훨씬 잘 보인다.
- 느낀 점: 불량을 3장밖에 못 잡았다는 걸 보고 질문의 답이 쉽지 않겠다는 생각이 들었다.
