# 데이터 출처

- 파일: `secom.csv` (5.7MB)
- 원출처: UCI Machine Learning Repository, SECOM 데이터 (McCann & Johnston, 2008) https://archive.ics.uci.edu/dataset/179/secom
- 이용 조건: CC BY 4.0 (출처를 밝히면 사용 가능)
- 내용: 반도체 제조 공정에서 웨이퍼 1장마다 기록한 센서 측정값과 최종 검사 결과(양품·불량)
- 측정 기간: 2008년 7월 19일 ~ 2008년 10월 17일
- 받은 날짜: 2026-10-15
- 크기: 1,567행 · 592열 (시각 1열 · 판정 1열 · 센서 590열)
- 개인 단위 정보: 공장 설비의 센서 측정값이며 사람에 대한 정보는 없음

## 파일을 만든 방법

원출처에는 파일이 두 개 있습니다.

- `secom.data`: 센서 측정값 590열. 열 이름이 없고 빈칸은 `NaN`으로 적혀 있음
- `secom_labels.data`: 판정(-1 = 양품, 1 = 불량)과 측정 시각

선생님이 두 파일을 행 순서대로 합쳐 `secom.csv` 한 파일로 만들었습니다. 이때 센서 열에 `sensor_001`~`sensor_590` 이름을 붙이고, 판정을 `fail`(1 = 불량, 0 = 양품)로 바꿨습니다. 측정값 자체는 바꾸지 않았습니다.

## 열 설명

| 열 | 뜻 | 이 프로젝트에서 |
|---|---|---|
| timestamp | 측정 시각. "일/월/연 시:분:초" 문자열(예: 19/07/2008 11:55:00). 시각 순서대로 정렬되어 있음 | 시간 순 분할에 사용 |
| fail | 최종 검사 결과. 1 = 불량, 0 = 양품 | 정답(레이블) |
| sensor_001 ~ sensor_590 | 공정 센서 측정값. 센서 이름과 단위는 공개되지 않음(익명) | 상수 열 116개와 빈칸이 절반을 넘는 열 28개를 빼고 446개를 입력 변수로 사용 |
